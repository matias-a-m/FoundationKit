# Changelog

Todas las versiones y cambios de FoundationKit.

---

## [1.0.0] - 2025-05-03

### Añadido
- `EmailValidator`: validación semántica de emails
- `PasswordValidator`: evaluación de fuerza de contraseñas
- `Logger`: logging con niveles, contexto automático y control global
- `DateFormatterProvider`: proveedor cacheado de DateFormatter
- `AppError`: modelo base de errores semánticos y unificados
- Extensión `Date+Utils`: formateo personalizado de fechas
- Pruebas unitarias (`XCTest`) para validadores y logger
- `README.md` profesional alineado con visión modular
